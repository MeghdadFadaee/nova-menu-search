# Security Policy

## Supported versions

| Version          | Supported |
|------------------|-----------|
| 1.x              | Yes       |
| Earlier versions | No        |

## Reporting a vulnerability

Please report security vulnerabilities privately through the repository's GitHub Security Advisory feature. Do not disclose the issue publicly until a fix is available.

Include the affected package version, Laravel and Nova versions, reproduction steps, expected behavior, and security impact. Reports will be reviewed as soon as practical, and coordinated disclosure will be arranged when the issue is confirmed.

Never include Nova credentials, application secrets, private menu data, or production session details in a report.
